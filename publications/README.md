# Publications

This directory is the public communication layer for the Cognitive Assets project.

It contains post-whitepaper materials designed to help the core argument travel across different public and institutional contexts without changing the whitepaper itself.

## Purpose

The `publications/` layer exists to support:

- public communication after the whitepaper release
- explanatory materials for broader audiences
- normalization of key concepts and terminology
- early specification work for reusable Cognitive Asset Packages
- template materials for GitHub-based preservation workflows

## Relationship to the whitepaper

This directory does not replace the whitepaper.

The whitepaper remains the primary conceptual and argumentative source for the project. The materials here serve as a bridge between the whitepaper and future publication or distribution venues, including:

- project website pages
- GitHub Releases
- Zenodo records
- future SSRN submissions
- future Medium or Substack essays
- future ResearchGate project materials
- GitHub template repositories

## Contents

- `launch-article.md` — a formal public release article for the whitepaper.
- `short-essays/` — five standalone explanatory essays for public platforms.
- `specification/` — an initial Cognitive Asset Package specification.
- `template-repo/` — a draft GitHub template repository for preserving human-AI collaboration context.

## Boundary

The materials in this directory are intended for communication, standardization, and reuse. They should not be treated as a replacement for the whitepaper, and they should not silently revise the whitepaper's claims.

If the core theory changes, the whitepaper should be updated or versioned explicitly. This directory should then be updated to reflect that change.

# Failure Record

This is a canonical MCAP file.

## Purpose

Use this file to preserve rejected paths, wrong assumptions, abandoned strategies, misleading outputs, and costly lessons in reusable form.

Failure records should help future work avoid repeating known mistakes. They should not become blame records.

### What Was Tried

Describe the attempt, assumption, strategy, framing, output, or path.

### Why It Seemed Plausible

Explain why this path initially appeared useful or reasonable.

### What Went Wrong

Describe the failure, limitation, misleading result, or unacceptable risk.

### What This Clarified

Explain what the failure revealed about the project, assumptions, constraints, or judgment rules.

### What Should Not Be Repeated

State what future work should avoid unless conditions change.

### Reopen Condition

Describe when this conclusion should be reconsidered.

### Evidence or Source Reference

Link or refer to relevant files, sources, logs, or decision entries if safe to include.

## What Should Not Go Here

Do not include blame-oriented personal records, sensitive incident details that should be redacted, unverified accusations, confidential material without permission, or failures without context and lesson learned.

# Specification

This directory contains early specification work for Cognitive Asset Packages.

The specification is intended to translate the whitepaper's conceptual argument into a practical, reviewable, and portable structure.

## Current version

- `cognitive-asset-package-spec-v0.1.md` — initial draft specification for a minimum Cognitive Asset Package.

## Status

Version `v0.1` is a draft. It should be treated as a starting point for discussion, testing, and revision rather than a final standard.

# Short Essays

This directory contains five standalone explanatory essays for public communication about Cognitive Assets.

Each essay is designed to be readable on platforms such as Medium, Substack, LinkedIn, or a project website. They explain the core idea from different angles without replacing the whitepaper.

## Essays

1. `01-what-is-a-cognitive-asset.md` — defines the concept and distinguishes it from ordinary files or notes.
2. `02-why-prompts-are-not-the-asset.md` — explains why prompts alone cannot preserve judgment or continuity.
3. `03-why-long-term-ai-collaboration-creates-assets.md` — explains how repeated human-AI work creates durable cognitive structures.
4. `04-why-losing-ai-memory-is-a-real-risk.md` — explains why memory loss in AI collaboration is not merely inconvenient.
5. `05-how-to-preserve-human-ai-collaboration.md` — offers a practical framework for preserving human-AI cognition.

## Editorial boundary

These essays should remain explanatory and non-promotional. They should avoid unsupported empirical claims, exaggerated predictions, or claims of universal applicability.

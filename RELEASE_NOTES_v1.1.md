# Cognitive Assets Whitepaper v1.1 — Publication Layer and Canonical MCAP Alignment

## Summary

Cognitive Assets Whitepaper v1.1 adds a public publication layer and implementation companion materials to the existing v1.0 whitepaper release.

- Added a launch article for public release context.
- Added a short essay series introducing key Cognitive Assets concepts.
- Added Cognitive Asset Package Specification v0.1.
- Added a canonical MCAP-aligned template repo.
- Added a v1.1 release directory containing the publication-layer materials.

- `publications/launch-article.md`

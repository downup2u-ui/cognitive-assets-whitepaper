# Review Status

This is a canonical MCAP file.

## Purpose

Use this file to track last reviewed dates, items requiring review, outdated decisions, uncertainty markers, retired assumptions, and human ownership of final judgment.

A cognitive asset must remain correctable. Review status helps distinguish active judgment from stale memory.
